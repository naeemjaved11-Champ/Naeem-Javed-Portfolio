Modern Dev Portfolio 🚀
​Welcome to my personal portfolio repository! This is a sleek, professional, and dark-themed portfolio designed to showcase my skills as a Frontend Developer & UI Specialist.
​I built this with a focus on clean typography, fluid responsiveness, and a premium user experience—all without relying on heavy frameworks.
​✨ Key Features
​Premium Dark UI: A modern aesthetic using a deep color palette and teal accents.
​Fully Responsive: Optimized for every screen—from large 4K monitors to mobile landscape modes.
​Built-in Professional Resume: A dedicated, polished resume section that’s easy to read and download.
​Dual Theme Support: Seamless Light/Dark mode switching using modern CSS techniques (:has selector).
​Performance First: Built with pure HTML and CSS for lightning-fast load times.
​🛠️ Tech Stack
​HTML5: Semantic structure for better SEO and accessibility.
​CSS3: Custom properties (variables), Flexbox, Grid, and advanced animations.
​Google Fonts: Poppins for a clean, modern look.
​Font Awesome: High-quality icons for better visual cues.
​📱 Preview
​The layout adapts perfectly to any device:
​Desktop: Wide, multi-column layout with hover effects.
​Mobile: Stacked components for easy thumb-navigation.
​Landscape: Specialized CSS rules to prevent content overlap on small wide screens.
